# 竞品分析 Agent（Competitor Analysis Agent）

> 一句话描述你的分析需求，自动产出一份带引用、可对话修改、可定时追踪的结构化竞品分析报告。

一个基于 **多 Agent 协同架构** 的智能竞品研究平台 Demo，支持竞品分析、市场研究、用户洞察、行业报告四大研究模块，全部功能内联在单个 HTML 文件中，无需安装、打开即用。

---

## ✨ 核心功能

### 1. 竞品分析（主场景）
- **对话式创建**：输入一句话需求，AI 自动解析分析对象、竞品、维度、专家视角
- **多 Agent 并行分析**：数据研究员 / 策略分析师 / 报告撰写师三线协同，进度实时可视化
- **8 章节报告**：执行摘要、竞品概览、功能对比、能力雷达、商业模式、用户反馈、竞争格局、策略建议
- **对话修改报告**：自然语言局部修改（如"加上飞书文档的定价对比"），只重跑相关章节
- **引用溯源**：事实性陈述标注引用，信源按权威度分级
- **定时追踪**：设置每日/每周/每月频率，自动追踪竞品动态

### 2. 市场研究 Agent（📊）
- TAM / SAM / SOM 市场规模建模（双向交叉验证）
- 增长趋势预测、竞争密度 / CR4 集中度
- 市场细分拆解（地区 / 客群 / 价格带）
- 定价与盈利模型、赛道机会评分

### 3. 用户洞察 Agent（💜）
- 38+ 平台用户声音聚合（VOC）
- 情感极性分析、痛点优先级矩阵
- 热门需求 Top5、用户画像分群、流失归因

### 4. 行业报告 Agent（📚）
- 12 家机构研报聚合
- 观点交叉验证与一致性评分
- 产业链图谱、政策监管、里程碑时间线
- 引用溯源与置信度标注

### 5. 通用能力
- **专家模式**：竞品分析 / 市场研究 / 用户研究 / 增长策略
- **多模型切换**：混元 Pro / DeepSeek-V4 / GLM-5 / Kimi-K2
- 收藏、分享、导出、后台运行、历史记录

## 🏗️ 技术架构

```
竞品分析 Agent
├── 用户层        对话输入 / 配置面板 / 报告预览 / AI 助手
├── Agent 核心层  Orchestrator 流程编排 + 多 Agent 协同 + Critic 质量自检
│   ├── 数据研究员  信息采集（对标 WorkBuddy 多智能体编排）
│   ├── 策略分析师  交叉分析
│   └── 报告撰写师  内容产出
├── 工具层        Web Search / Web Fetch / 引用管理 / 导出
└── 数据层        向量库（已读内容）+ 信源元数据
```

三个研究模块复用同一套 Agent 状态机与 Orchestrator，通过配置驱动差异化（角色 / 阶段 / 报告章节 / 可视化组件 / 配色），体现"共性抽象 + 场景定制"的产品工程思路。

- **落地能力**：从用户洞察、产品设计、Agent 架构到工程实现的全流程
